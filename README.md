## 📌 Overview

This project is created to practice **Excel 2024 formulas and data analysis** using Student, Employee, Sales data.

It covers commonly used Excel functions for calculating, searching, filtering and working with data.

---

## ✨ Key Features

* Data entry and formatting
* Relative and Absolute References
* IF, Nested IF, AND & OR
* COUNTIFS, SUMIFS & AVERAGEIFS
* VLOOKUP, XLOOKUP & XMATCH
* INDEX & MATCH
* TEXT functions
* INDIRECT & OFFSET
* Date and Time functions
* ROUND, CEILING & FLOOR
* FILTER function

---

## 📂 Project

### Dataset Used

## 📚  Excel Fundamental Practice

### 1. Data & Formatting

* Enter and format data
* Apply currency and date formats
* Use relative and absolute references

### 2. Conditional Formulas

* Classify student grades using IF
* Apply Nested IF
* Use IF with AND/OR
* Calculate discounts based on conditions

### 3. Conditional Analysis

* Count students using COUNTIFS
* Calculate sales using SUMIFS
* Find average scores using AVERAGEIFS

### 4. Lookup Functions

* Find student names using VLOOKUP
* Find product prices
* Fetch employee salaries using XLOOKUP
* Find product positions using XMATCH

### 5. Dynamic Search

* Use INDEX + MATCH
* Create flexible searches
* Use INDIRECT and OFFSET for dynamic references

### 6. Text, Date & Math

* Extract names using LEFT and FIND
* Change text using UPPER and LOWER
* Calculate age and date differences
* Use ROUND, CEILING and FLOOR

### 7. FILTER

* Extract students based on their scores
* Create filtered lists from the dataset
